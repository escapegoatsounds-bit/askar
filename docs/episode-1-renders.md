# Episode 1 renders

The render files live on the editing PC in `E:\land of rebirth\Episode 1`, one folder per frame (`NN Title`, numbered as in [the frame guide](episode-1-frame-guide.md)). They are **not** in git; this page lists what is where. Made from `Episode 1/_renders-index.json` (sorted 28 Nov 2026), which also records every move so a file can be put back.

- **217** renders sorted into **42 of 66** frames; **57** more in side folders.
- Frames still without renders: 8, 10, 12, 14, 15, 16, 17, 21, 25, 35, 37, 38, 40, 42, 43, 44, 45, 47, 58, 59, 61, 62, 64, 66.
- The Desk shows each frame's renders under that frame's pictures; Askar has them in the project folder **Episode 1 · renders** (one board per part, plus *Key art and extras* and *Old version and unsorted*).
- Both apps read the files in place (`/local/files/renders/...`, set by `LOR_RENDERS`, default `E:\land of rebirth`) and never change or delete them.

## How to add new renders

Drop the file into its frame folder. To show it in the apps, run the sorting/import scripts again (they skip anything already added), or add it by hand on the Desk frame.
